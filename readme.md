# Resumo Explicativo: Licença AGPL-3.0 ⚖️

Uma página web simples, responsiva e visual para explicar a licença **GNU AGPL-3.0** em português de forma clara e acessível.


[📖 meu rsumo da Licença AGPL-3.0 na íntegra](https://brunomoraesf.github.io/Licenca-AGPL-3.0/)

[🌐 Ver a pagina da Licença AGPL-3.0 na íntegra](https://www.gnu.org/licenses/agpl-3.0.html)

## 💡 Por que este projeto existe?

Eu criei este arquivo HTML para incluir nos meus próprios projetos. Acredito que é fundamental que as pessoas tenham a liberdade de usar, estudar e modificar o código que eu desenvolvo. Mas, ao mesmo tempo, quero garantir que essa mesma liberdade seja passada adiante para os próximos usuários. 

A licença AGPL-3.0 é perfeita para isso: ela permite o uso livre, mas exige que qualquer modificação (mesmo as disponibilizadas apenas via rede/web) também tenha seu código-fonte aberto. Esta página serve para explicar essas regras sem complicação.
